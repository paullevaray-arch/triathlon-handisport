# Triathlon Tous Ensemble

Site web statique présentant un triathlon (fictif) organisé pour les personnes à mobilité réduite. Projet étudiant.

## Contenu

| Fichier | Rôle |
| --- | --- |
| `index.html` | Présentation générale (étudiant, formation, université) |
| `evenement.html` | Description de l'événement sportif |
| `programme.html` | Programme et déroulé de la journée |
| `infos-pratiques.html` | Lieu, matériel, accessibilité |
| `inscription.html` | Formulaire d'inscription (HTML simple, non relié à un serveur) |
| `style.css` | Feuille de style commune |
| `images/` | Les 3 photos du site |

## Lancer le site en local

Depuis le dossier du projet :

```bash
python3 -m http.server 8000
```

Puis ouvrir <http://localhost:8000> dans un navigateur.
On peut aussi simplement double-cliquer sur `index.html`.
